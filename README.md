# Oreon System Manager

One place for packages, repositories, Docker and Distrobox containers, Flatpak apps, and drivers.

## Why isn't there a large commit history?
A common practice our team will make is to develop locally, then upload the tarball to our tarball dump (tarballs.oreonhq.com) which speeds up testing. We only push here once we get things working, and also once we have more than one person working on said project. Oreon System Manager has been in development since summer 2024, with previous iterations being tested, and a couple rewrites. Development has stalled between late 2024 and most of 2025, until development was resumed in late 2025.
